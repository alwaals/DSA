
# Linear Search
Find the target element from the array by looping every value
Tc: O(n)

# Binary Search
Searching the target element using divide and search. So divides whole array into half and if mid>target then search in left most array else right most
TC:O(Logn)

## Bubble Sort
We will sort each pair and find the largest value and place it at right most index. So for every iterative we will find greatest of its array.
TC : O(n^2)
Sc : O(1)
It's not efficient but simple to understand.
